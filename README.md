# Personal Portfolio Website

Welcome to my personal portfolio website! 👋

This project was created as part of my web development learning journey and showcases my skills, projects, and basic web development knowledge.

## About Me

I am a B.Sc. Information Technology student interested in technology, web development, programming, cybersecurity, and emerging technologies.

## Features

- Responsive portfolio design
- Home, About Me, Skills, Projects, and Contact sections
- Mobile-friendly navigation menu
- Contact form with Formspree integration
- Accessible HTML structure
- Responsive CSS design
- JavaScript-based interactivity

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Formspree
- GitHub Pages
